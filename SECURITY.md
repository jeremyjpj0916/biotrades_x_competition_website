# Security reporting

Use the [private GitHub vulnerability reporting form](https://github.com/jeremyjpj0916/biotrades_x_competition_website/security/advisories/new) or contact the repository owner privately through GitHub. Include affected routes or versions, the impact and enough detail for maintainers to investigate. Keep account information, session values and production credentials out of reports and public issues.

The public competition and authenticated participant and admin routes are in scope. Test against your local development copy with synthetic data.
